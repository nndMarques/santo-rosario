# Terço

Aprenda a rezar o terço e reze todos os dias.

- **Aprender:** o terço desenhado conta por conta, com a oração de cada conta (português, latim, inglês e italiano).
- **Rezar:** guiado, um mistério por vez (gozosos, luminosos, dolorosos, gloriosos), ou o rosário completo.
- **Constância:** marcar o terço rezado, ofensiva de dias seguidos e marcos.
- **Lembrete** diário (calendário do celular e aviso do navegador).
- **Privacidade:** sem conta, sem servidor. Tudo fica guardado só no aparelho.

Feito a partir do [Lumen](https://github.com/nndMarques/lumen), só com a parte do terço.

## Rodar no computador

```bash
python -m http.server 5181
```

Abra http://localhost:5181. HTML, CSS e JavaScript puros, sem etapa de build.
